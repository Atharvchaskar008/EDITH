# The Race to Save Space - Interactive Frontend

Interactive 3D WebGL and multimedia presentation of the United Nations space sustainability feature *The Race to Save Space*.

## Overview
This frontend contains the full UN space sustainability web experience, including:
- Interactive 3D WebGL Sputnik orbit visualization
- Real-time scroll timeline & notable space milestones
- UN Space treaties & debris cascade visualization
- Embedded media (video, audio, infographics)
- Dynamic localized data models

## Quick Start

### Run with Node.js
```bash
npm start
# or
node server.js
```

### Access in Browser
- Direct URL: [http://localhost:3000/en/content/feature/theracetosavespace/](http://localhost:3000/en/content/feature/theracetosavespace/)
- Auto-redirect: [http://localhost:3000/](http://localhost:3000/)

### Windows Shortcut
Double-click `run.bat` to launch the server directly.
